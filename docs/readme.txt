China Set: Export Rail Vehicles Add-on

The export rail vehicles sector of the China Set of OpenTTD: the locomotives,
multiple units, coaches and wagons that the Chinese rolling stock industry
built for railways abroad.

The set is designed to be used together with China Set: Trains
(https://github.com/OpenTTD-China-Set/China-Set-Trains) and China Set:
Narrow Gauge Add-on.  Vehicles of the three sets can be coupled to each other.

The vehicle code in this set is generated from the declarative tables in
data/ by genpnml.py; see README.md and data/README.md.
