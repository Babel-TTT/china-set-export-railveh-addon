## 1. 总则

《中国包：出口铁路载具附加包》是 OpenTTD 中国包系列中的出口铁路载具部分。\
本附加包在 GPL v2 许可证下发布。

该套装收录中国大陆铁路工业为境外铁路建造的机车、动车组、客车与货车，
以及历史上由中国开往邻国的国际联运车厢。

本附加包设计为与《中国包：火车》和《中国包：窄轨附加包》**同时加载**使用。
三个套装的车辆可以互相编组；为此在 `src/functions.pnml` 中互相校验了 GRF ID。

由于出口市场的实际需要，本包包含准轨、俄罗斯宽轨（1520 mm）、套轨和米轨车辆，
轨道类型沿用母包的半标准化命名规则：

| 首字母 | 轨距            | 典型用途                     |
| ------ | --------------- | ---------------------------- |
| `S`    | 1435 mm         | 世界大部分地区               |
| `B`    | 1520 mm         | 俄罗斯、中亚、蒙古           |
| `D`    | 1435 / 1520 mm  | 可变轨距车辆、套轨           |
| `N`    | 1067 / 1000 mm  | 东南亚、非洲                 |
| `n`    | 762 / 600 mm    | 工矿铁路与轻便铁路           |

可用参数名单：

| 名称                                       | 功能                                             | 默认值 |
| ------------------------------------------ | ------------------------------------------------ | ------ |
| 装载速度                                   | 改变装载速度                                     | 普通   |
| 购买费用                                   | 改变购买费用                                     | 25%    |
| 运行费用                                   | 改变运行费用                                     | 25%    |
| 货物贬值周期                               | 改变货物贬值周期（保鲜度/舒适度）                | 100%   |
| 单独设置货车的货物贬值周期                 | 单独设置邮件与货物车厢的贬值周期，在上项上叠加   | 100%   |
| 涂装换代后建造的出口车辆默认使用新涂装     | 决定涂装换代后新建车辆是否自动采用新涂装         | 是     |

## 2. 添加车辆

车辆是**数据**，不是代码。新增一辆车只需：

1. 在 `data/locomotives.csv`、`data/coaches.csv`、`data/wagons.csv` 或
   `data/unit_wagons.csv` 中新增一行（各列含义见
   [data/README.md](data/README.md)）；
2. 如需涂装，在 `data/liveries.csv` 中补充涂装行；如需按货物改变外观，
   在 `data/cargo_variants.csv` 中补充对应行；
3. 运行 `make gen` —— 车辆 ID、开关链、精灵集、采购菜单顺序以及语言字符串
   都会自动生成；
4. 把模型放入 `gfx/<目录>/<id>.vox`。如果车辆有多套涂装或多种货物外观，
   每个精灵基名都需要一个 `.vox`。`make gen` 会为它们自动生成占位模型，
   因此即使还没有美术资源，工程也可以直接编译通过。

`src/usercode.pnml`、`src/vehicleid.pnml`、`src/vehiclesort.pnml`
均为生成文件，请勿手工修改 —— 每次构建都会被覆盖。
